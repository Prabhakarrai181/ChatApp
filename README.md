# WebChat

A real-time chat application with video calling.

## Features

- User registration and login
- Real-time messaging
- Online/offline user status
- Image/file sharing (agar project me hai)
- Video calling using WebRTC
- Socket.IO based real-time communication
- Responsive UI

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- Socket.IO

### Database
- MongoDB

### Video Calling
- WebRTC
- STUN

## Project Structure

webchat/
├── client/
└── server/

## Installation

### Clone Repository

git clone YOUR_GITHUB_REPO_URL

### Frontend

cd client
npm install
npm run dev

### Backend

cd server
npm install
npm start

## Environment Variables

Create `.env` files and add the required environment variables.
